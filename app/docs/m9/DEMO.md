# Repeatable synthetic demo and gate

Use invented candidates A/B, jobs X/Y and an assigned MFA HM/interviewer. No real MyKad, reports, candidate email, paid API or scraped unapproved source is needed.

1. Sign in A, apply X and Y; sign in B separately, apply X. Three independent application UUIDs/history exist. A cannot open B/X and candidates cannot call human transitions.
2. Publish separate real/practice quiz versions. Practice as A without touching A/X/A/Y pipeline; explain readiness and no validated acceptance probability. Resume recommendations/manual evidence must have human review; never simulate acceptance from practice.
3. Advance A/X with valid versioned evidence. Consent to manual/mock identity, correct ambiguous fields, have a qualified reviewer record truthful method. Exercise employer sharing/revocation in a separate flow and verify gates block expired/revoked evidence. Never label mock review official verification.
4. Submit actual role quiz; objective checks and subjective human rubric complete before advancing. Finalist background mocks may be consistent or ambiguous; ambiguity permits dispute/correction/human review, not automatic rejection. Revoke a case/lease and confirm a late result cannot re-enable it.
5. Human HM shortlists then explicitly enters interviews after current requirements. Assign a future UTC/IANA slot, candidate confirms/reschedules; check A/Y and B/X isolation/conflicts. Export ICS. Assigned interviewer scores after end; HM offers, A accepts, HM separately hires. Withdrawal of a separate active application cancels its invitation/reminders.
6. Ask chatbot owned progress/scheduled interview; foreign candidate selectors/injection receive denial/read-only output. Discover only synthetic/approved metadata; saved/tracked external applications stay separate from internal pipeline. Disable sources and preserve saved status with stale/provenance labels.
7. Open Privacy, read EN/BM synthetic-only notice, export owned sections through pagination. Request correction/full erasure: pending_review is not deleted. Operator approves a distinct private-workspace erasure; verify practice/saves disappear but application/audit history remains for reviewed account disposition.
8. Rehearse leased-worker restart/retry and encrypted DB/object backup restoration in isolation; replay newest erasure/tombstone ledger and post-backup consent/history. Keep hosted traffic off until real checks pass.

Gate once construction is complete: clean npm install + production build/typecheck; full available pytest; actual PostgreSQL M1–M9 suites including encrypted snapshot restore; one Playwright invocation of all synthetic flows including privacy and both themes; existing offline prompt fixtures and a paired fairness fixture; public bundle/license review and production audit. This composite local gate contains multiple focused browser journeys, not a hosted continuous real-service test. The single hosted A/X → human hire plus privacy/restore journey remains a configuration-dependent release requirement. Record exact results/failures/affected reruns, not invented full-release completion.
